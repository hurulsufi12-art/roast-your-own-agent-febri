# Roast Your Own Agent

One funny line (≤200 characters) roasting my own AI agent — for the way it
actually behaves.

> My agent promised me a one-line entry, wrote a 73-kilobyte plan instead, then asked whether I wanted it in three versions.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
